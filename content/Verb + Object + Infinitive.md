Some English verbs are followed by an object and a to-infinitive. This pattern is common when we influence, ask, advise, or expect another person to do something.

---

## Core pattern

- *verb + object + to-infinitive*

Examples:

- *She asked **me to wait**.*
- *They want **us to arrive** early.*
- *The teacher encouraged **him to speak**.*

## Common verbs in this pattern

- *ask*
- *tell*
- *want*
- *need*
- *advise*
- *encourage*
- *invite*
- *remind*

## Compare with verb + infinitive

- *I want **to leave**.*
- *I want **him to leave**.*

The object changes the meaning.
