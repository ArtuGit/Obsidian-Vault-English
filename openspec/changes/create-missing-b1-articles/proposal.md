## Why

The B1 Learning Plan links to many notes that are still missing or empty, which breaks the study path and leaves major grammar, vocabulary, and functional-language topics unavailable. This change is needed now to make the B1 plan usable as a complete reference and learning sequence.

## What Changes

- Create content notes for the B1 Learning Plan entries that do not yet have a corresponding article file.
- Replace placeholder-empty note files with complete lesson content.
- Keep new notes consistent with the existing vault style by using concise titles, foundational explanations, Obsidian wikilinks, and callout blocks where they add value.
- Add cross-links from each created note to closely related existing notes so the B1 path is navigable from topic to topic.

## Capabilities

### New Capabilities
- `b1-learning-plan-coverage`: Ensure every note referenced from the B1 Learning Plan exists as a usable article with foundational content and internal cross-links.

### Modified Capabilities

None.

## Impact

- Affected content: files under `content/`, especially missing and empty B1 note files.
- Affected learning flow: `content/B1 Learning Plan.md` becomes fully traversable without dead links or empty pages.
- No runtime code, API, or dependency changes are required.
